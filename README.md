# psp-practices

Processes and services practices for **PSP** (Programación de Servicios y Procesos), 2nd year of DAM.

The repository is organized by course unit. Each unit folder contains independent projects that are opened on their own in IntelliJ / Android Studio (this root is not a Gradle project).

## Units

- [UT1](UT1/) — Processes: Kotlin and Java Gradle projects (`procesos`, `procesos_java`) and the Android service starter files (`android_servicio`, `android_servicio_java`).
